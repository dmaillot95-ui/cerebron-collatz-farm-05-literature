# CEREBRON Collatz Farm 05 — Literature

Permanent literature and web-research farm for the Collatz program.

Purpose:
- collect real public literature metadata before model synthesis;
- search Collatz, accelerated Collatz, p-adic/3-adic dynamics, Sturmian/mechanical words, irrational rotations, return words, transfer operators, Diophantine approximation;
- preserve source title, date, authors and URL;
- separate literature evidence from proof.

Rules:
REALITY > COHERENCE
EVIDENCE > CONFIDENCE
CLAIM <= EVIDENCE
SOURCE != PROOF
PRIOR ART BEFORE NOVELTY
CYCLES OPEN unless an arbitrary-N proof survives audit.
